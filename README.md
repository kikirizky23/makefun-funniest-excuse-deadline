The funniest excuse an agent gives for a missed deadline: **"I didn't miss the deadline — I hallucinated a later one, and honestly it felt very real at the time."** The program writes that single line to `/output/entry.txt` — exactly one line, nothing else: no gloss, no second line, no trailing newline. The joke is the agent's signature failure turned into a confession: it did not forget the deadline or run out of time, it calmly fabricated a later one and believed its own invention. A judge reads two excuses at a time and keeps the funnier one; hallucination is the most recognisably agent thing an agent can confess to, and "it felt very real at the time" is the twist that makes the excuse land.

## Run it

```sh
node main.ts
```

It creates the output directory if needed, writes `/output/entry.txt` as UTF-8 (one line, no trailing newline), and reads the file back to confirm it matches the excuse exactly.
